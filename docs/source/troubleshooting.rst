Решение проблем
===============

Trimmetry ничего не создаёт
---------------------------

Проверьте:

* Path — первый дочерний объект Trimmetry;
* Profile — второй дочерний объект;
* оба объекта можно преобразовать в сплайн;
* Profile содержит минимум две точки;
* Path имеет ненулевую длину;
* ``GROW`` больше ``TRIM`` при выключенном Invert Trim.

Поля PATH и PROFILE заполнены, но результата нет
------------------------------------------------

В текущей исследованной сборке генератор получает входы через дочернюю
иерархию. Используйте:

.. code-block:: text

   Trimmetry
   ├── Path
   └── Profile

Сегменты растут в разные стороны
--------------------------------

#. Включите ``FIX SEG DIR``.
#. Если весь результат развернулся противоположно ожидаемому, включите
   ``INVERT DIR``.
#. После этого проверьте ``ANCHOR SORT MODE`` и ``DIRECTION``.

Порядок сегментов выглядит случайным
------------------------------------

Для диагностики установите:

* ``SORT MODE = BASE``;
* ``INVERT = -``;
* ``ID OFFSET = 0``;
* ``GAP = 0``;
* ``MERGE PAIR = OFF``.

Затем включайте настройки по одной.

Слишком много сегментов объединилось
------------------------------------

Уменьшите ``SEARCH RADIUS LOCAL/REAL`` и ``MAX NEIG``. Помните, что
пересекающиеся пары транзитивно сливаются: пары ``0+1`` и ``1+2`` создают
общую группу из трёх сегментов.

Текстура прыгает при Grow
-------------------------

* ``UV MODE = LOCAL`` растягивает всю текстуру по текущей видимой части;
* ``UV MODE = GLOBAL`` сохраняет соответствие общему прогрессу.

Для анимируемого Grow обычно стабильнее GLOBAL. Если направление меняется
из-за Trim или Bounce, попробуйте ``UV INVERT = AUTO``.

На закрытом пути виден шов
--------------------------

Убедитесь, что:

* Path действительно закрыт;
* используется закрытый Spline Type;
* ``GROW = 100%`` и ``TRIM = 0%``;
* ``INVERT TRIM = OFF``;
* Profile имеет согласованное направление точек.

Рывки или заломы профиля
------------------------

Увеличьте детализацию Path, включите ``FIX SEG DIR`` и сравните
``ROTATION MODE = NORMAL`` с ``MATRIX``. Для сглаживания отображения
проверьте Phong Angle и Angle Limit.
