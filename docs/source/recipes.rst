Практические рецепты
====================

Последовательное появление сегментов
------------------------------------

Используйте:

.. code-block:: text

   GROW            0% → 100%
   SPEED_MOD       TIME
   OVERLAP         0%
   SORT_MODE       BASE

Сегменты будут появляться в исходном порядке и без перекрытия.

Появление по длине
------------------

Установите ``SPEED_MOD = LENGTH``. Длинные группы получат больше времени,
а визуальная скорость движения границы станет равномернее.

Плавная передача между сегментами
---------------------------------

Увеличьте ``OVERLAP``. Начните с ``10–20%`` и подбирайте значение по
количеству групп и желаемому ритму.

Рост от центра наружу
---------------------

.. code-block:: text

   SYMMETRY        ON
   ANCHOR_MODE     CENTER
   PROPORTIONAL    ON
   SPLINE_TYPE     OPEN PROPORTIONAL

Для радиального набора попробуйте ``ANCHOR_MODE = CIRCLE``.

Зеркальная последовательность
-----------------------------

.. code-block:: text

   SORT_MODE       MIRROR
   MIRROR_DIR      ON или OFF
   ANCHOR_SORT_MODE MIRROR

``ID_OFFSET`` позволяет повернуть начальную точку последовательности.

Бегущая видимая полоса
----------------------

Анимируйте Grow и Trim с одинаковым интервалом:

.. code-block:: text

   Кадр 0:    TRIM 0%,  GROW 20%
   Кадр 100:  TRIM 80%, GROW 100%

Для циклического движения попробуйте подходящий ``TRIM_BOUNCE_MODE``.

Скручивание при появлении
-------------------------

.. code-block:: text

   ROTATION_START       0°
   ROTATION_END         720°
   ROTATION_DEFORM_MODE GLOBAL

Дополнительно задайте Function Curve для ускорения вращения к концу.

Объединение близких сегментов
-----------------------------

#. Включите ``MERGE PAIR``.
#. Выберите ``SEARCH METHOD = REAL``.
#. Установите небольшой ``SEARCH RADIUS REAL``.
#. Ограничьте ``MAX NEIG``, чтобы не получить одну большую группу.
