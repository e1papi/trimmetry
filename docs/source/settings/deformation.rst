Масштаб и вращение
==================

SCALE
-----

SCALE START / SCALE END
~~~~~~~~~~~~~~~~~~~~~~~

Масштаб профиля в начале и конце видимой цепочки:

* ``100%`` — исходный размер;
* ``0%`` — профиль схлопнут;
* значения выше ``100%`` увеличивают профиль.

SCALE CURVE
~~~~~~~~~~~

Function Curve перераспределяет переход от Start к End. Горизонтальная
ось — положение вдоль цепочки, вертикальная — коэффициент интерполяции.

SCALE DEFORM MODE
~~~~~~~~~~~~~~~~~

LOCAL
   Переход Start → End нормализуется по текущей видимой цепочке. При
   изменении Grow весь градиент остаётся растянут по видимой части.

GLOBAL
   Переход привязан к общему прогрессу роста. При частичном Grow видна
   соответствующая часть полного градиента.

ROTATION
--------

ROTATION START / ROTATION END
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Угол поворота профиля в начале и конце цепочки. Интерфейс допускает
значения значительно больше полного оборота, поэтому можно создавать
многократное скручивание.

ROTATION CURVE
~~~~~~~~~~~~~~

Управляет нелинейным переходом между начальным и конечным углами.

ROTATION MODE
~~~~~~~~~~~~~

NORMAL
   Поворачивает готовые кольца вокруг локальной оси пути по формуле
   Родрига. Это совместимый, визуально предсказуемый режим.

MATRIX
   Встраивает поворот непосредственно в базис матриц профиля. Полезен,
   когда вращение должно следовать ориентации Sweep-матриц.

ROTATION DEFORM MODE
~~~~~~~~~~~~~~~~~~~~

``LOCAL`` и ``GLOBAL`` работают аналогично режимам Scale: либо
нормализуют вращение по видимой цепочке, либо привязывают его к общему
прогрессу Grow.

.. image:: /_static/gifs/additional-settings/additional-settings-rotation.gif
   :alt: rotation
   :width: 100%
   :align: center

Практические сочетания
----------------------

Появление из точки
   ``SCALE START = 0%``, ``SCALE END = 100%``, режим ``LOCAL``.

Постоянное скручивание
   ``ROTATION START = 0°``, ``ROTATION END = 720°``, режим ``GLOBAL``.

Обратное схлопывание
   ``SCALE START = 100%``, ``SCALE END = 0%``.
