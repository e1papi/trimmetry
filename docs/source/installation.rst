Установка
=========

Совместимость
-------------

Эта документация подготовлена по сборке Trimmetry, установленной в
**Cinema 4D 2024**. Совместимость с другими выпусками Cinema 4D зависит
от Python API соответствующей версии.

Установка плагина
-----------------

#. Закройте Cinema 4D.
#. Скопируйте папку ``Trimmetry`` целиком в папку ``plugins`` вашей
   установки Cinema 4D.
#. Убедитесь, что внутри находятся как минимум:

   .. code-block:: text

      Trimmetry/
      ├── Trimmetry.pyp
      ├── LOGO.png
      └── res/

#. Запустите Cinema 4D.
#. Найдите **Trimmetry** в списке генераторов или через поиск команд.

Пример пути для Cinema 4D 2024:

.. code-block:: text

   C:\Program Files\Maxon Cinema 4D 2024\plugins\Trimmetry

Если плагин не появился
-----------------------

Проверьте:

* скопирована ли вся папка ``res``;
* не оказался ли файл в двойной вложенности
  ``Trimmetry/Trimmetry/Trimmetry.pyp``;
* соответствует ли сборка версии Cinema 4D;
* есть ли сообщения Python в консоли Cinema 4D.
