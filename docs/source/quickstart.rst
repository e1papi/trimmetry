Быстрый старт
=============

Минимальная сцена
-----------------

#. Создайте сплайн, который будет траекторией.
#. Создайте небольшой Circle, Rectangle или собственный сплайн профиля.
#. Создайте объект **Trimmetry**.
#. Перетащите Path под Trimmetry первым дочерним объектом.
#. Перетащите Profile туда же вторым дочерним объектом.

Иерархия должна выглядеть так:

.. code-block:: text

   Trimmetry
   ├── Path
   └── Profile

.. warning::

   В исследованной сборке генератор читает первый и второй дочерние
   объекты напрямую. Поля ``PATH`` и ``PROFILE`` видны в интерфейсе,
   однако для надёжной работы используйте именно иерархию выше.

Стартовые настройки
-------------------

Для первой проверки используйте:

.. list-table::
   :header-rows: 1
   :widths: 35 25 40

   * - Параметр
     - Значение
     - Результат
   * - ``GROW``
     - ``100%``
     - Вся доступная геометрия видима.
   * - ``TRIM``
     - ``0%``
     - Начало диапазона не срезано.
   * - ``SYMMETRY``
     - ``ON``
     - Рост идёт от Anchor в обе стороны.
   * - ``SPLINE_TYPE``
     - ``OPEN PROPORTIONAL``
     - Удобный режим для первого открытого пути.
   * - ``SPEED_MOD``
     - ``TIME``
     - Все группы получают равное время.

Первая анимация
---------------

#. На нулевом кадре установите ``GROW = 0%`` и создайте ключ.
#. На последнем кадре установите ``GROW = 100%`` и создайте ключ.
#. Если сегментов несколько, настройте ``OVERLAP``.
#. При необходимости измените их порядок в :doc:`settings/segment-sort`.
#. Настройте точку раскрытия в :doc:`settings/anchor-sort`.

Path и Profile
--------------

Path
   Может содержать несколько сегментов. Количество точек каждого сегмента
   определяет плотность колец и, следовательно, детализацию результата.

Profile
   Должен содержать минимум две точки. Закрытый Profile создаёт замкнутое
   поперечное сечение, открытый — ленту.
